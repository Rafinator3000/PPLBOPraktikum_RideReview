# PPLBOPraktikum_RideReview

laravel file, database phpmyadmin
requires XAMPP Apache and MySQL

Terminal commands:
php artisan serve (runs server)
npm run dev (runs assets)

create new database "ridereview" in phpmyadmin
php artisan migrate (create tables)

php artisan db:seed --class=LocationSeeder (seeds example locations)
